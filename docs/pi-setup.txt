1 Prerequisites
===============

  Clone the repository (e.g. to `~/ieos'). Enable SPI for the OLED:
  `sudo raspi-config' → Interface Options → SPI → Yes; reboot if
  prompted.

  Run the bootstrap script as your normal login user (not root).


2 Install
=========

  ,----
  |   cd ~/ieos
  |   bash scripts/pi-bootstrap.sh
  `----


3 Sudo (USB mount / unmount / `blkid', system time)
===================================================

  Run once after clone so the app can use `sudo -n' without a password
  prompt:
  ,----
  |   cd ~/ieos
  |   sudo bash scripts/pi-sudo-setup.sh
  `----


4 Run (from repo root)
======================

  ,----
  |   cd ~/ieos
  |   ./ie.sh
  `----
