1 Install
=========

  ,----
  |   cd ~/ieos
  |   python3 -m venv .venv
  |   source .venv/bin/activate
  |   pip install -r gui/requirements.txt
  |   pip install -r ieos/requirements.txt
  `----


2 Sudo (USB mount / unmount / `blkid', system time)
===================================================

  Run once after clone so the app can use `sudo -n' without a password
  prompt:
  ,----
  |   cd ~/ieos
  |   sudo bash scripts/pi-sudo-setup.sh
  `----


3 Run (from repo root)
======================

  ,----
  |   cd ~/ieos
  |   ./ie.sh
  `----
